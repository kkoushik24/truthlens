# TruthLens Forensic Test Samples Directory

This directory contains reference and synthetic test samples designed to benchmark and validate the TruthLens multimodal forensics pipeline across images, video, audio, and claims.

---

## 📁 Sample Assets Index

| Filename | Modality | Ground Truth Type | Forensic Characteristics & Tampering Markers |
| :--- | :---: | :---: | :--- |
| `clean_photo.jpg` | Image | Authentic Capture | Clean JPEG with valid Canon EOS 80D camera metadata and capture timestamp. Uniform compression profile. |
| `stripped_photo.jpg` | Image | Stripped Metadata | Standard image with all EXIF metadata headers removed, simulating social media or messaging app upload. |
| `edited_photo.jpg` | Image | Spliced Composite | Base image recompressed with an injected high-frequency pixel patch in region `[200, 20, 300, 100]`, with `Adobe Photoshop 2024` EXIF tag. |
| `sample_video.mp4` | Video | Spliced Sequence | 2-second 12 fps video featuring smooth color gradients, with an injected abrupt red flash and noise spike at Frame #18, plus an audio track. |
| `synthetic_chord_test.wav` | Audio | Mathematical Sine Chord (DSP Test) | Signal-processing test only, NOT human speech. Generated by `generate_audio_samples.py` using 7 sine waves (220-7000 Hz) + white noise for DSP frequency benchmarking. Must NEVER appear in demos, eval sets, or accuracy claims. |
| `synthetic_cutoff_audio.wav` | Audio | Synthetic / Bandwidth Cutoff | 16 kHz WAV recording passed through a steep 10th-order Butterworth low-pass filter at 3 kHz (simulating legacy TTS vocoders) with an amplitude surge at $t=1.0\text{s}$. |

## 🛠️ Recommended Additions for Live Testing

To expand the benchmark test suite during live hackathon demos, consider adding:

1. **AI-Generated Photo (`ai_generated_portrait.jpg`)**:
   - A photo generated via Midjourney v6 or Stable Diffusion XL.
   - Observe the Hugging Face AI detector response and lack of hardware EXIF.
2. **Context-Mismatched Caption (`mismatched_claim.txt`)**:
   - A claim such as: *"Massive blizzard in Miami July 2024"* paired with a tropical beach image.
   - Observe the vision-language alignment flag.
3. **Short Real Video (`phone_camera_clip.mp4`)**:
   - A 5–10 second mobile phone recording.
   - Observe continuous temporal metrics and mobile codec metadata (H.264/AAC).
4. **Short Edited Video (`jumpcut_spliced_clip.mp4`)**:
   - A clip with a dramatic scene cut or injected object splice.
   - Observe the temporal consistency drop and flagged frame index.
5. **Synthetic Deepfake Audio (`elevenlabs_clone.mp3`)**:
   - A short speech sample generated from ElevenLabs or PlayHT.
   - Observe the spectrogram prosody and acoustic classifier score.

## 🔄 Regeneating Built-In Test Samples

All synthetic test media can be regenerated at any time using the bundled generator scripts:

```bash
# Regenerate sample images
python samples/generate_samples.py

# Regenerate sample video
python samples/generate_video_samples.py

# Regenerate sample audio
python samples/generate_audio_samples.py
```
